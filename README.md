## 📌 Sobre o Repositório
Este repositório contém os **scripts, exercícios e exemplos práticos** desenvolvidos ao longo da disciplina **Aplicações Práticas e Teoria dos Grafos**.  
O objetivo é servir como base de estudo, prática e consulta para os alunos, contemplando a implementação de conceitos teóricos utilizando **Python** e bibliotecas específicas para manipulação e visualização de grafos.

---

## 🎯 Objetivos da Disciplina
- **Modelar problemas reais** utilizando conceitos de Teoria dos Grafos.  
- **Implementar algoritmos clássicos** como Dijkstra, Bellman-Ford e algoritmos para Árvores Geradoras Mínimas.  
- **Explorar bibliotecas Python** para criação, manipulação e visualização de grafos.  
- Desenvolver **habilidades de documentação e testes de código**.  
- Integrar teoria e prática, aproximando a disciplina de aplicações do mundo real.

---

## 🛠 Metodologia de Ensino
A abordagem será **integrada**, combinando:
1. **Exposição teórica** com recursos visuais e lousa para apresentar conceitos como conectividade e planaridade.  
2. **Prática em laboratório**, implementando os algoritmos discutidos em sala.  
3. **Exercícios progressivos**, aumentando gradualmente a complexidade para consolidar o aprendizado.  
4. **Projetos práticos**, como modelagem de redes sociais, rotas de transporte e problemas de otimização.  

Cada conceito teórico será seguido por **atividades práticas em Python**, aplicando os algoritmos e técnicas vistos.

## 📦 Tecnologias e Ferramentas
- **Linguagem:** Python 3.x
